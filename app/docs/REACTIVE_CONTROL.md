# 三种无功控制：第一步控制验证（2026-10-26）

采用方案二：保留标幺电压输出，按28377D的伏特输出增益作单位等效换算。以下为DSP实际使用值：

| 模式 | INV_CMD.q_mode | Kp_QV | Ki_QV |
| --- | --- | --- | --- |
| 恒电压 ConstV | 0 | 0 | 0 |
| 恒无功 ConstQ | 1 | 0 | 40/155.56 ≈ 0.25713551 |
| 无功下垂 Droop | 2 | 10/155.56 ≈ 0.06428388 | 0 |

选择/锁存封装于app/control/reactive_control.c。默认ConstV。选择在并网前通过上位机应用，实际进入INV_GRID_CONNECTED时锁存并初始化VSG无功环。离网VF、预同步电压跟踪、已有有功VSG、原始虚拟功角算法、P_filter遥测和40秒试验保持。

## 控制定义与单位

沿用Qe_pu=INV_FEEDBACK.Qe/5000和INV_CMD.q_ref标幺给定，电压修正仍为标幺值乘SYS_V_BASE_V（155.56 V相电压峰值）。旧工程PI输出直接是V，因此旧Kp=10、Ki=40必须分别除以155.56，不能直接放进新环。源常量QV_LEGACY_DROOP_KP=10、QV_LEGACY_CONSTQ_KI=40保留在reactive_control.c，ApplyGains统一除以SYS_V_BASE_V；不要在其他位置重复换算。Qref默认0，1pu=5000var；界面Q/Qref显示kvar。

- ConstV：修正为0，电压双环跟踪并网时锁存的电容端电压幅值，不代表PCC或理想电源端恒压，Q允许变化。
- ConstQ：纯积分(40/155.56)*(Qref-Qe_pu)，通过改变电压参考跟踪Qref；换成物理电压后的未饱和积分速率等效于旧Ki=40。积分输出和最终物理电压限幅均回算；达到调制能力边界不保证Qref可实现。
- Droop：标幺比例斜率10/155.56，Ki=0不积分。以并网瞬间工作点为无扰锚：deltaV_pu=(10/155.56)*(当前Q误差-入网Q误差)。固定q_bias_pu=-(10/155.56)*入网Q误差与积分器分开保存。本次不改变这一入网偏置策略，所以仅是增益/单位等效，不声称所有初始化行为与旧工程完全相同。

三种输出均保留±0.3pu（±46.668V）修正限制及原物理电压限幅、抗饱和和A/B时序。此次只修正之前多出的155.56倍增益，不重新整定其他环节。显示Q仍来自三相dq计算，不是P_filter。未饱和对照：50var变化(0.01pu)对应比例电压变化0.1V；500var固定误差(0.1pu)持续10ms，对应积分电压变化0.04V，不再是15.556V/6.2224V。单位等效不代表闭环稳定性保证，仍需HIL小扰动验证。

## 上位机操作

1. 停机确认PWM关闭、断路器断开，CCS采用原来匹配板卡晶振的FLASH配置刷新/构建/下载。20MHz LaunchPad导出位于artifacts/CPU1_LAUNCHXL_FLASH；10MHz通用版位于artifacts/PowerCompareFlash，不能混用。
2. 启动新版WPF并连接CAN，在“并网前无功模式”下拉框选择ConstV/ConstQ/Droop，点击“应用所选模式”。允许待机/离网/预同步/待并网阶段选择，但已请求合闸或实际并网后禁止设置。
3. 等待“DSP已确认”以及“DSP已选”匹配选择。只改变下拉框不生效；有新模式反馈的固件，选择未匹配/应答未确认/反馈超时会禁止发送并网命令。
4. 继续原孤岛→预同步→并网流程。并网时模式生效，界面显示当前生效模式与锁定状态。并网后Q环立即运行，Pref仍为0等待实验按钮；Qref非0时即使Pref=0也可能有无功电流。
5. 切换模式需急停→解除→在并网前重新选择应用→重新孤岛/预同步/并网。停机清除active标志，但保留已选模式，便于相同模式下连续A/B。

## ANN和A/B边界

三种模式已迁移对应CPU阻抗网络：ConstV输入Q(var)/虚拟功角(deg)，ConstQ/Droop输入虚拟功角(deg)/无功环电压修正(V)。电压特征由v_delta_pu乘155.56还原，不使用输出总幅值。三种阻抗模型共享同一个J/D整定网络，L(mH)除1000变为H后输入；详见[ANN_CPU.md](ANN_CPU.md)。
三种模式都支持固定A和自适应B。A仅预测，B在9s/24s尝试应用有效参数；原40秒Pref/GPIO流程及应用开关不改。CCS观察ANN_CTRL.model_mode/ann_V_input/R_est/L_est/J_apt/D_apt。
40秒CSV工况备注附加DSP当前无功模式和收到的Qref（无新鲜值则未知），不改变原CSV布局。比较A/B时必须同无功模式、Qref、HIL工况。网络来自旧工程，控制工作点/电压锚差异仍需HIL验证。

## CAN扩展（经典标准帧1Mbps，小端）

- 0x200/DLC4：10 A5 5A 00选择ConstV；11 A5 5A 00选择ConstQ；12 A5 5A 00选择Droop。0x10等均十六进制命令字。原01～06、独立0x100急停保持。
- 0x20A/DLC8/100ms：byte0版本1，byte1已选模式0/1/2，byte2生效模式0/1/2或255未启用，byte3 bit0锁定，byte4/5接受设置版本号u16，byte6设置结果0无/1接受/2拒绝，byte7最近设置模式。
- 0x20B/DLC8/100ms：float32实测Q(var)和float32 Qref(var)。原201～209不改布局，206/207仍1ms。

上位机用新版本号+匹配模式+接受结果确认，不把旧回显当新设置成功；2秒未确认提示超时、不自动重发。急停不依赖新模式反馈。没有20A的旧固件无法设置模式，但保留旧监控/运行命令兼容。
TX槽从9扩至11，现有消息RAM布局容量足够，无新引脚或SysConfig操作。低速共9帧/100ms，加功率2000帧/s约2090帧/s，现场仍需检查cana_power_drop_count不增加。
